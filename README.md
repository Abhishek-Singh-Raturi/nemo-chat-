# 🐠 Nemo - AI Assistant

> **v1.0** | A beautiful AI chat interface with liquid glass theme, multiple API providers, and modern UI features.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub](https://img.shields.io/badge/GitHub-Ai__nemo__chat-blue?logo=github)](https://github.com/Abhishek-Singh-Raturi/Ai_nemo_chat)

---

## ✨ Features

### 🤖 Multiple AI Providers
- **OpenAI** - GPT-4o, GPT-4o Mini
- **Anthropic** - Claude Sonnet 4, Claude 3.5
- **Google Gemini** - Gemini 2.0 Flash, 1.5 Pro
- **Groq** - Llama 3.3, Mixtral, Gemma
- **OpenRouter** - 100+ models
- **Custom API** - Your own endpoints

### 🎨 7 Beautiful Themes
- Dark (Default) | Light | Cyber | Cherry | Midnight | Aurora | Ember

### 💻 Code Features
- Syntax highlighting with Highlight.js
- Copy code button
- Multiple language support

### 📱 User Experience
- Chat history with save/load
- Profile system with avatar
- Tasks & Calendar
- Image attachment support
- Responsive design
- Blinking Nemo eyes
- Copy message button
- Donate QR popup

### 🔐 Privacy
- API keys stored locally only
- No data sent to external servers
- Open-source

## 🚀 Quick Start

```bash
git clone https://github.com/Abhishek-Singh-Raturi/Ai_nemo_chat.git
cd Ai_nemo_chat
start index.html
```

---

## ⚙️ API Setup

1. Click ⚙️ Settings
2. Go to API Settings → + Add
3. Get key from provider:
   - OpenRouter: https://openrouter.ai/
   - Groq: https://console.groq.com/
   - OpenAI: https://platform.openai.com/api-keys
4. Select model → Start chatting!
